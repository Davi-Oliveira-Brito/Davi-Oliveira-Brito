## Projeto em destaque

### Finance Manager *(em desenvolvimento)* 

Sistema de gerenciamento financeiro pessoal, focado em **organização, controle e visualização de dados financeiros**.

**Objetivo do projeto**
- Consolidar conhecimentos em backend
- Trabalhar com regras de negócio reais
- Evoluir em arquitetura e boas práticas

**Stack**
- Backend: **C# + .NET**
- Banco de dados: **PostgreSQL**
- Frontend: **React / Next.js**

**Principais desafios**
- Uso de tecnologias fora da zona de conforto
- Estruturação de APIs REST
- Modelagem de dados e regras financeiras
- Integração backend/frontend

📌 Projeto desenvolvido **individualmente**, desde a concepção até a implementação.
