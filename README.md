**Full Stack Developer** · São Paulo, Brazil

I build web applications, internal systems, and automations using **Python and Django** on the backend,
**Next.js and React** on the frontend. From database design and APIs to user interfaces
and deployment, I focus on software that solves real business problems.

Right now I'm a Junior Full Stack Developer at [SuccesPar](https://succespar.com.br),
